---

### 3. **Confluence Adjustments: Over-Correction**

**Problem:** Macro adjustments moved scores too much in volatile environments

**Example (Mar 8, 18:00):**
- Gold base: 0.80 → +0.05 (RISK_OFF) +0.05 (sentiment) = **0.90** (too high)
- BTC base: 0.75 → -0.05 (RISK_OFF) = **0.70** (at threshold, no action)

**Root Cause:**
- RISK_OFF helped gold too much
- RISK_OFF hurt crypto too much
- Binary adjustments (±0.05) don't account for degree

**Fix Needed:**
```
# Gradient-based adjustments
macro_adjustment = {
    "EXTREME_RISK_OFF": -0.08,  # VIX > 35
    "RISK_OFF": -0.03,           # VIX 25-35 (current)
    "NEUTRAL": 0.00,             # VIX 15-25
    "RISK_ON": +0.03,            # VIX < 15
}

# Asset-specific modifiers
if asset == "GOLD" and macro == "RISK_OFF":
    adjustment = +0.03  # Gold benefits (safe haven)
elif asset in ["BTC", "ETH"] and macro == "RISK_OFF":
    adjustment = -0.03  # Crypto suffers (risk asset)
```
